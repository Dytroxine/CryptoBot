# CryptoBot

Telegram бот, который следит за курсами криптовалют на нескольких биржах и присылает уведомление, когда разница курсов достигает порога, выбранного пользователем.

## Возможности

- Сравнивает курсы на Binance, Bitfinex, Cryptomus, Coinbase и Kraken
- Работает с 14 монетами: XMR, SHIB, BTC, TRX, BCH, AVAX, ETH, DOGE, DASH, LTC, DAI, SOL, BNB, MATIC
- Пользователь выбирает базовую биржу, монету и порог разницы: 0.1, 0.5, 1, 2 или 5 процентов
- Курсы со всех бирж запрашиваются параллельно через asyncio и aiohttp
- В уведомлении указан курс на базовой бирже, а также курс и процент разницы на остальных
- Бот корректно обрабатывает блокировку пользователем, удалённый чат и лимиты Telegram

## Как это работает

1. Пользователь выбирает биржу, монету и порог в боте.
2. Подписка сохраняется в `source/users.json`.
3. Каждые 60 секунд бот запрашивает актуальные курсы на всех биржах.
4. Для каждой подписки считается разница в процентах между базовой биржей и остальными.
5. Если разница хотя бы на одной бирже достигла порога, пользователь получает сообщение.

## Установка

Нужен Python 3.8 или новее.

```bash
git clone https://github.com/Dytroxine/CryptoBot.git
cd CryptoBot
pip install aiogram==2.25.1 aiohttp requests
mkdir source
```

Получите токен у @BotFather и укажите его в `main.py`:

```python
API_TOKEN = 'ваш_токен'
```

## Запуск

```bash
python main.py
```

## Использование

1. Отправьте боту `/start`.
2. Нажмите Start tracking rate.
3. Выберите базовую биржу.
4. Выберите монету.
5. Выберите порог разницы.

Кнопка Stop tracking удаляет все ваши подписки.

## Формат данных

В `source/users.json` подписки хранятся так:

```json
{
    "1": {
        "chat_id": "123456789",
        "exchange": "Binance",
        "coin": "BTC",
        "diff": "1"
    }
}
```

## Примечания

- Некоторые пары доступны не на всех биржах. В этом случае для такой биржи в сообщении будет написано Failed to retrieve data.
- Курсы обновляются раз в 60 секунд, а уведомления отправляются с паузой 90 секунд.
- Файл `source/users.json` содержит chat_id пользователей, не публикуйте его в репозитории.
